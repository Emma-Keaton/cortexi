# Hybrid Style Examples

## Overview
Style Mix allows 1-3 styles per video/scene. Templates are suggestions only.

## Example Mixes

### Explainer
**Styles:** Storybook Collage + Stickman IK + UI Infographics
- Modules: Asset + Overlay + Character + Overlay
- Use: Educational explainer with paper collage assets, stick figure narrator, data overlays
- Template: Explainer

### Funny Skit
**Styles:** Stickman Motion + Hyper Frames + Cinematic Flow
- Modules: Character + Camera + Transition + Camera + Transition
- Use: Comedy skit with dynamic camera, fast cuts, cinematic handheld feel
- Template: Funny Skit

### Product Video
**Styles:** Cinematic Flow + One Take + UI Infographics
- Modules: Camera + Transition + Camera + Transition + Overlay
- Use: Product launch with continuous camera moves showing UI overlays
- Template: Product

### Brand Video
**Styles:** Storybook Collage + Cinematic Flow
- Modules: Asset + Overlay + Camera + Transition
- Use: Brand storytelling with collage assets and film motion
- Template: Brand

### Introduction
**Styles:** Stickman Whiteboard + Hyper Frames
- Modules: Character + Asset + Camera + Transition
- Use: Intro with sketch animation and dynamic frames
- Template: Intro

### Education
**Styles:** Storybook Collage + UI Infographics + Stickman IK
- Modules: Asset + Overlay + Overlay + Character
- Use: Classroom style with collage, charts, and stickman
- Template: Education

## Rules
- Max 3 styles per scene
- Single style is default
- Templates do not lock styles – user can change freely
- Preview shows modules combined and engine type
